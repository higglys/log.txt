# Задание 5. Фильтрация логов

## Описание
Программа читает файл `log.txt`, выводит все строки, содержащие слово `ERROR`, и подсчитывает количество таких строк.

## Подготовка
1. Создайте файл `log.txt` в папке с программой.
2. **Вставьте в файл `log.txt` сообщения программы**, каждое сообщение должно находиться на отдельной строке.
3. Добавьте несколько строк со словом `ERROR`, чтобы проверить работу программы.
4. Сохраните файл.

## Как запустить
1. Запустите Python-программу.
2. Программа автоматически прочитает файл `log.txt`.
3. На экране будут показаны все строки с `ERROR` и их общее количество.

## Пример

Содержимое файла `log.txt`:

```text
INFO: Программа запущена
ERROR: Ошибка подключения
INFO: Подключение восстановлено
ERROR: Файл не найден
WARNING: Недостаточно памяти
```

Результат работы программы:

```text
ERROR: Ошибка подключения
ERROR: Файл не найден
Количество ошибок: 2
```

## Важно
- Файл `log.txt` должен находиться в той же папке, что и программа.
- Перед запуском необходимо самостоятельно заполнить `log.txt`.
- Учитываются только строки, содержащие слово `ERROR`.
- Каждая найденная строка выводится на экран и учитывается при подсчёте общего количества ошибок.
